# BoraJogar

**BoraJogar** é uma landing page decorativa e visualmente moderna, projetada para promover uma plataforma fictícia de jogos online! Inspirada no charme dos jogos *Friv* e no design sofisticado da *Steam*, o objetivo é transmitir uma experiência atraente e envolvente para os visitantes. 🕹️✨  

## 🌟 O que o projeto oferece  
- 🎨 **Design Moderno:** Um layout limpo e profissional, desenvolvido para impressionar.  
- 📱 **Responsividade:** Adaptado para exibição em diferentes dispositivos, garantindo uma boa experiência para todos os usuários.  
- 💻 **Simulação Realista:** Embora seja apenas uma demonstração, o site transmite a sensação de uma plataforma real de jogos.  

## 🚀 Tecnologias Utilizadas  
O **BoraJogar** foi criado utilizando:  
- 🌐 **HTML**  
- 🎨 **CSS**  
- ⚡ **JavaScript**  
- 💎 **Bootstrap**  

## 🔥 Como Visualizar o Projeto  
1. Faça o clone do repositório:  
   ```bash
   git clone https://github.com/seu-usuario/BoraJogar.git
   ```
2. Navegue até o diretório do projeto:
   ```bash
   cd BoraJogar
   ```

3. Abra o arquivo **index.html** no navegador e veja a landing page em ação!✨

## 💡 Sobre o Projeto
Este projeto foi desenvolvido como um exercício de front-end, com foco em design responsivo e experiência do usuário. O BoraJogar é ideal para demonstrar habilidades em desenvolvimento web e uso de frameworks como o Bootstrap. 🎉
